# Linux System Administration & Security Lab

## Overview

This repository documents my hands-on learning and practical work with Linux system administration and cybersecurity fundamentals.

The project combines structured Linux terminal training, practical exercises, Bash scripting, Git version control, and OverTheWire Bandit challenges.

## Objectives

- Develop strong Linux command-line skills.
- Understand Linux file and directory management.
- Learn Linux permissions, ownership, users, and groups.
- Practice system and process inspection.
- Develop basic Bash automation skills.
- Apply Linux knowledge to cybersecurity challenges.
- Document practical security-related findings.
- Build a professional cybersecurity portfolio.
